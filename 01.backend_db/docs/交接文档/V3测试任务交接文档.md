# 数据库模块 V3 测试任务交接文档

## 1. 测试目标

独立验证 A 模块 V3 操作审计日志的只追加存储、查询、迁移和公开契约，并完整回归 V1、V2。测试对象是当前 `dev-db` 工作区，目标包版本 `3.0.0`，目标迁移 `f8a2d4c6b901`。

## 2. 范围

重点验证：

- `operation_audit_log` 表字段、外键、可空规则和索引；
- `OperationAuditLogCreate` 的长度、空白、额外字段和UTC时间处理；
- `record`、`get`、`list`；
- 项目编码和操作用户引用校验；
- 系统级、未登录失败和项目级记录；
- 多条件筛选、分页、稳定排序和 `include_total=False`；
- CRUD不提交、Service提交与失败回滚；
- 公开接口不返回ORM且没有更新、启停、删除；
- V3迁移降级、重新升级和模型一致性；
- Python包构建及全部回归测试。

不测试 FastAPI、JWT、登录流程、鉴权、Redis、MQTT、WebSocket、UE5以及B定义的动作代码业务含义。

## 3. 安全要求

只允许在名称以 `_test` 结尾的独立测试库执行降级或写入。不得降级开发库，不得修改源码，不得提交或推送。测试报告应记录实际分支、提交、工作区状态、Python/MySQL版本、测试数量、迁移往返和包构建结果。

## 4. 当前开发侧验证基线

- 定向测试：25项通过；
- 当前全量测试：129项通过；
- 测试库迁移往返：通过；
- `alembic check`：无差异；
- 包构建：`smart_beam_twin_backend_db-3.0.0-py3-none-any.whl` 成功。

这些结果只是开发侧基线，独立测试任务需要自行复测并输出结论。
