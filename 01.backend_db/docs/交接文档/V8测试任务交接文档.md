# V8 运输交接记录测试任务交接文档

## 1. 目标和边界

独立验证 V8 是否符合 `docs/V8运输交接记录设计草案.md`、数据字典和 A-B 接口说明。测试任务可修改测试及测试报告，不修改业务实现、迁移或正式契约。

- 依赖标签：`backend-db-v7.0.0`
- 目标包版本：`8.0.0`
- 目标迁移：`f8c2d4e6a709`
- 测试库名必须以 `_test` 结尾

## 2. 必测范围

1. `OUTBOUND`、`TRANSFER`、`ARRIVAL` 的地点必填规则；
2. `ACCEPTED`、`REJECTED` 事实保存；
3. 项目梁、全局梁和项目隔离；
4. 记录人用户快照、移交人和接收人文本快照；
5. 编码及外部幂等、不同内容冲突和两键分裂冲突；
6. 首次并发创建只保留一条；
7. 停用项目不能新建，完全相同幂等重试仍成功；
8. 作废、重复作废和并发作废不覆盖首次信息；
9. 筛选、关键词、时间范围、页码分页、无总数分页和稳定排序；
10. 创建失败完整回滚；
11. 不修改梁状态，不追加 V5 事件或 V3 审计日志；
12. 表字段、外键、唯一约束、作废检查约束和索引；
13. DTO、Protocol、`transport_records` 组合入口及 wheel 隔离导入；
14. 迁移升级、降级、重新升级和 `alembic check`；
15. V1 至 V7 完整回归。

## 3. 非目标

不测试或开发运输调度、车辆/司机/承运企业档案、GPS 轨迹、电子围栏、附件、签字、二维码/RFID、HTTP、权限页面或自动梁状态联动。

## 4. 通过标准

- 定向和完整测试无失败、错误、跳过或预期失败；
- 并发用例重复运行无死锁、超时或偶发失败；
- 测试库最终为 `f8c2d4e6a709 (head)` 且模型无差异；
- 不残留 V8 测试数据；
- 报告区分自动测试结果、外部系统限制和未覆盖风险。
