# 智能建梁数字孪生平台 V6 梁工序执行记录数据字典

- 契约版本：V6.0（暂行规则）
- 表名：`beam_process_execution`
- 迁移版本：`d4a6f8b0c217`
- 规则来源：[`V6梁工序执行记录暂行设计.md`](V6梁工序执行记录暂行设计.md)

## 1. 表用途

保存一片梁在一道已配置工序上的一次已经结束的执行事实。该表不保存生产计划、进行中任务、审批、工序顺序或设备测点。

## 2. 字段

| 字段 | MySQL 类型 | 可空 | 默认 | 键/约束 | 含义 |
|---|---|---:|---|---|---|
| `id` | `BIGINT` | 否 | 自增 | 主键 | 内部技术标识 |
| `project_id` | `BIGINT` | 是 | 无 | FK → `project.id` | 梁所属项目；空表示 V1 全局域 |
| `execution_code` | `VARCHAR(64)` | 否 | 无 | 唯一 | 对外稳定执行编码 |
| `beam_id` | `BIGINT` | 否 | 无 | FK → `beam.id` | 被执行工序的梁 |
| `process_definition_id` | `BIGINT` | 否 | 无 | FK → `process_definition.id` | 工序定义 |
| `result_code` | `VARCHAR(32)` | 否 | 无 | DTO 枚举 | `SUCCESS`、`FAILED`、`ABORTED` |
| `started_at` | `DATETIME(6)` | 否 | 无 | 检查约束 | 实际开始 UTC 时间 |
| `finished_at` | `DATETIME(6)` | 否 | 无 | `finished_at >= started_at` | 实际结束 UTC 时间 |
| `actor_user_id` | `BIGINT` | 是 | 无 | FK → `app_user.id` | 可空平台操作用户 |
| `actor_name` | `VARCHAR(128)` | 是 | 无 | Service 校验 | 操作人名称快照或外部人员标识 |
| `source` | `VARCHAR(32)` | 否 | 无 | DTO 枚举 | `MANUAL`、`SYSTEM`、`IMPORT`、`DEVICE` |
| `external_record_id` | `VARCHAR(128)` | 是 | 无 | 与 `source` 联合唯一 | 外部来源幂等标识 |
| `supersedes_execution_id` | `BIGINT` | 是 | 无 | 自 FK、唯一 | 被本记录纠正的已作废记录 |
| `remark` | `VARCHAR(500)` | 是 | 无 | — | 执行说明 |
| `is_voided` | `BOOLEAN` | 否 | ORM 为 `FALSE` | 检查约束 | 是否已受控作废 |
| `voided_at` | `DATETIME(6)` | 是 | 无 | 检查约束 | 首次作废 UTC 时间 |
| `voided_by_user_id` | `BIGINT` | 是 | 无 | FK → `app_user.id` | 可空作废用户 |
| `voided_by_name` | `VARCHAR(128)` | 是 | 无 | Service 校验 | 作废人名称快照或外部人员标识 |
| `void_reason` | `VARCHAR(500)` | 是 | 无 | 作废时必填 | 首次作废原因 |
| `created_at` | `DATETIME(6)` | 否 | ORM 写入 | — | 入库 UTC 时间 |
| `updated_at` | `DATETIME(6)` | 否 | ORM 写入 | — | 最后修改 UTC 时间，正常只因作废变化 |

所有外键删除规则均为 `RESTRICT`。数据库不存储项目、梁、工序的业务编码副本；公开 DTO 通过关联读取业务编码且不返回 ORM 对象。

## 3. 索引

| 名称 | 字段 | 用途 |
|---|---|---|
| `execution_code` 唯一索引 | `execution_code` | 编码读取和全局唯一保护 |
| `uq_beam_process_execution_source_external` | `source, external_record_id` | 外部请求幂等保护 |
| `uq_beam_process_execution_supersedes` | `supersedes_execution_id` | 防止修正关系分叉 |
| `ix_beam_process_execution_project_finished_id` | `project_id, finished_at, id` | 项目执行历史 |
| `ix_beam_process_execution_beam_finished_id` | `beam_id, finished_at, id` | 单梁履历 |
| `ix_beam_process_execution_process_finished_id` | `process_definition_id, finished_at, id` | 工序履历 |

## 4. 对外枚举和修改原则

结果和来源在数据库中使用字符串保存，在 Schema 层限制当前可写值。以后新增编码时保留历史编码读取能力，不依赖枚举顺序或固定数量。

记录创建后没有任意更新和物理删除接口。纠错只能先作废原记录，再创建带 `supersedes_execution_code` 的新记录。规则或字段发生变化时，同时更新本数据字典、暂行设计、A-B 接口说明和迁移版本。
