## `beam_transport_handover`

| 字段 | 类型 | 可空 | 约束/含义 |
|---|---|---|---|
| `id` | `BIGINT` | 否 | PK，自增 |
| `project_id` | `BIGINT` | 是 | FK→`project.id`，跟随梁 |
| `handover_code` | `VARCHAR(64)` | 否 | UNIQUE，稳定交接编码 |
| `beam_id` | `BIGINT` | 否 | FK→`beam.id` |
| `handover_type` | `VARCHAR(32)` | 否 | `OUTBOUND`/`TRANSFER`/`ARRIVAL` |
| `result_code` | `VARCHAR(32)` | 否 | `ACCEPTED`/`REJECTED` |
| `from_location` | `VARCHAR(255)` | 是 | 起点快照 |
| `to_location` | `VARCHAR(255)` | 是 | 终点快照 |
| `carrier_name` | `VARCHAR(128)` | 是 | 承运单位快照 |
| `vehicle_no` | `VARCHAR(64)` | 是 | 车辆标识快照 |
| `sender_name` | `VARCHAR(128)` | 是 | 移交人快照 |
| `receiver_name` | `VARCHAR(128)` | 是 | 接收人快照 |
| `occurred_at` | `DATETIME(6)` | 否 | UTC 交接时间 |
| `actor_user_id` | `BIGINT` | 是 | FK→`app_user.id` |
| `actor_name` | `VARCHAR(128)` | 是 | 记录人快照 |
| `source` | `VARCHAR(32)` | 否 | `MANUAL`/`SYSTEM`/`IMPORT`/`DEVICE` |
| `external_record_id` | `VARCHAR(128)` | 是 | 与 `source` 组合 UNIQUE |
| `remark` | `VARCHAR(500)` | 是 | 备注 |
| `is_voided` | `BOOLEAN` | 否 | 是否作废 |
| `voided_at` | `DATETIME(6)` | 是 | 作废 UTC 时间 |
| `voided_by_user_id` | `BIGINT` | 是 | FK→`app_user.id` |
| `voided_by_name` | `VARCHAR(128)` | 是 | 作废人快照 |
| `void_reason` | `VARCHAR(500)` | 是 | 作废原因 |
| `created_at` | `DATETIME(6)` | 否 | UTC 创建时间 |
| `updated_at` | `DATETIME(6)` | 否 | UTC 更新时间 |

索引：`(project_id, occurred_at, id)`、`(beam_id, occurred_at, id)`、`handover_code` 唯一索引以及 `(source, external_record_id)` 唯一索引。所有外键删除策略为 `RESTRICT`。

该表只表达已发生的交接事实，不表达运输任务、车辆档案、轨迹或梁当前运输状态。
