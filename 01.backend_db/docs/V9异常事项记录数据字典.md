# V9 异常事项记录数据字典

## 1. 表说明

表名：`abnormal_issue`

用途：保存已经由业务方、外部系统或设备判定成立的异常事项，以及开始处理、解决和关闭的当前节点快照。

## 2. 字段

| 字段 | 类型 | 可空 | 说明 |
|---|---|---:|---|
| `id` | `BIGINT` | 否 | 自增技术主键 |
| `project_id` | `BIGINT` | 否 | 所属项目，外键到 `project.id` |
| `issue_code` | `VARCHAR(64)` | 否 | 稳定异常事项编码，全表唯一 |
| `beam_id` | `BIGINT` | 是 | 可选关联梁，外键到 `beam.id` |
| `device_code` | `VARCHAR(64)` | 是 | 外部设备稳定编码，不建立设备外键 |
| `category_code` | `VARCHAR(32)` | 否 | 异常分类 |
| `issue_type_code` | `VARCHAR(64)` | 否 | 具体异常类型代码 |
| `severity` | `VARCHAR(32)` | 否 | `INFO`、`WARNING`、`CRITICAL` |
| `status` | `VARCHAR(32)` | 否 | `OPEN`、`IN_PROGRESS`、`RESOLVED`、`CLOSED` |
| `title` | `VARCHAR(128)` | 否 | 异常标题 |
| `message` | `VARCHAR(500)` | 否 | 异常摘要，不保存完整原始报文 |
| `occurred_at` | `DATETIME(6)` | 否 | 异常发生时间，UTC |
| `reported_by_user_id` | `BIGINT` | 是 | 可选上报用户 |
| `reported_by_name` | `VARCHAR(128)` | 是 | 上报人名称快照 |
| `source` | `VARCHAR(32)` | 否 | `MANUAL`、`SYSTEM`、`IMPORT`、`DEVICE` |
| `external_record_id` | `VARCHAR(128)` | 是 | 外部幂等标识 |
| `processing_started_at` | `DATETIME(6)` | 是 | 开始处理时间 |
| `processing_by_user_id` | `BIGINT` | 是 | 开始处理用户 |
| `processing_by_name` | `VARCHAR(128)` | 是 | 开始处理人名称快照 |
| `resolved_at` | `DATETIME(6)` | 是 | 解决时间 |
| `resolved_by_user_id` | `BIGINT` | 是 | 解决用户 |
| `resolved_by_name` | `VARCHAR(128)` | 是 | 解决人名称快照 |
| `resolution_summary` | `VARCHAR(500)` | 是 | 解决摘要，进入 `RESOLVED` 后必填 |
| `closed_at` | `DATETIME(6)` | 是 | 关闭时间 |
| `closed_by_user_id` | `BIGINT` | 是 | 关闭用户 |
| `closed_by_name` | `VARCHAR(128)` | 是 | 关闭人名称快照 |
| `close_note` | `VARCHAR(500)` | 是 | 可选关闭备注 |
| `created_at` | `DATETIME(6)` | 否 | A 写入的 UTC 创建时间 |
| `updated_at` | `DATETIME(6)` | 否 | A 写入的 UTC 更新时间 |

## 3. 约束

- 主键：`id`；
- 唯一：`issue_code`；
- 唯一：`(source, external_record_id)`；
- 外键：`project_id -> project.id`；
- 外键：`beam_id -> beam.id`；
- 四个用户字段分别外键到 `app_user.id`；
- `ck_abnormal_issue_status_fields` 保证状态和处理节点字段一致；
- `ck_abnormal_issue_processing_actor` 保证开始处理时间和处理人同时成立或同时为空。

## 4. 索引

| 索引 | 字段 | 用途 |
|---|---|---|
| `ix_abnormal_issue_project_occurred_id` | `project_id, occurred_at, id` | 默认项目异常时间线 |
| `ix_abnormal_issue_project_status_occurred_id` | `project_id, status, occurred_at, id` | 项目未关闭事项和状态列表 |
| `ix_abnormal_issue_project_category_status_occurred_id` | `project_id, category_code, status, occurred_at, id` | 分类异常看板 |
| `ix_abnormal_issue_beam_occurred_id` | `beam_id, occurred_at, id` | 单梁异常历史 |
| `ix_abnormal_issue_project_device_occurred_id` | `project_id, device_code, occurred_at, id` | 设备关联异常历史 |

## 5. 边界

本表不是设备时序表、原始报警报文表、通知队列表或通用工单表。`device_code` 不建立设备档案关系；`message`、解决摘要和关闭备注不得保存密码、令牌、设备密钥或完整请求报文。
