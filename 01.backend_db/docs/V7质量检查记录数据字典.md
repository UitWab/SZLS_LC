# 智能建梁数字孪生平台 V7 数据字典：质量检查域

- 文档状态：开发完成，待独立测试、审计与冻结
- 包版本：`7.0.0`
- 迁移版本：`e7b9c1d3f605`
- 数据库：MySQL 8.0

## 1. `beam_quality_inspection`

保存对一片梁进行的一次独立检查或验收事实。

| 字段 | 类型 | 可空 | 约束或索引 | 含义 |
|---|---|---|---|---|
| `id` | `BIGINT` | 否 | PK，自增 | 内部主键 |
| `project_id` | `BIGINT` | 是 | FK→`project.id` | 跟随梁项目；空表示兼容全局梁 |
| `inspection_code` | `VARCHAR(64)` | 否 | UNIQUE | 稳定检查编码 |
| `beam_id` | `BIGINT` | 否 | FK→`beam.id` | 被检查梁 |
| `process_definition_id` | `BIGINT` | 是 | FK→`process_definition.id` | 可选关联工序 |
| `process_execution_id` | `BIGINT` | 是 | FK→`beam_process_execution.id`，INDEX | 可选关联 V6 执行记录 |
| `previous_inspection_id` | `BIGINT` | 是 | 自引用 FK，INDEX | 前次检查记录 |
| `inspection_type_code` | `VARCHAR(64)` | 否 | — | 开放的稳定检查类型代码 |
| `result_code` | `VARCHAR(32)` | 否 | — | `PASS`、`FAIL` |
| `inspected_at` | `DATETIME(6)` | 否 | 组合索引 | UTC 检查时间 |
| `actor_user_id` | `BIGINT` | 是 | FK→`app_user.id` | 检查用户 |
| `actor_name` | `VARCHAR(128)` | 是 | — | 检查人快照 |
| `source` | `VARCHAR(32)` | 否 | 组合唯一约束 | 记录来源 |
| `external_record_id` | `VARCHAR(128)` | 是 | 与 `source` UNIQUE | 外部幂等标识 |
| `summary` | `VARCHAR(500)` | 是 | — | 结论摘要 |
| `is_voided` | `BOOLEAN` | 否 | 检查约束 | 是否作废 |
| `voided_at` | `DATETIME(6)` | 是 | 检查约束 | 首次作废时间 |
| `voided_by_user_id` | `BIGINT` | 是 | FK→`app_user.id` | 作废用户 |
| `voided_by_name` | `VARCHAR(128)` | 是 | 检查约束 | 作废人快照 |
| `void_reason` | `VARCHAR(500)` | 是 | 检查约束 | 作废原因 |
| `created_at` | `DATETIME(6)` | 否 | — | A 写入 UTC |
| `updated_at` | `DATETIME(6)` | 否 | — | 最后更新时间 |

组合索引为 `(project_id, inspected_at, id)`、`(beam_id, inspected_at, id)` 和 `(process_definition_id, inspected_at, id)`。所有外键删除规则均为 `RESTRICT`。

## 2. `beam_quality_inspection_item`

保存主记录下不可变的检查项快照。

| 字段 | 类型 | 可空 | 约束或索引 | 含义 |
|---|---|---|---|---|
| `id` | `BIGINT` | 否 | PK，自增 | 内部主键 |
| `inspection_id` | `BIGINT` | 否 | FK、INDEX | 所属质量检查 |
| `item_code` | `VARCHAR(64)` | 否 | 与主记录 ID UNIQUE，`utf8mb4_bin` | 精确区分大小写的检查项代码 |
| `item_name` | `VARCHAR(128)` | 否 | — | 检查项名称快照 |
| `requirement_text` | `VARCHAR(500)` | 是 | — | 验收要求快照 |
| `observed_value` | `VARCHAR(128)` | 是 | — | 实际值文本 |
| `unit` | `VARCHAR(32)` | 是 | — | 单位快照 |
| `result_code` | `VARCHAR(32)` | 否 | — | `PASS`、`FAIL`、`NOT_APPLICABLE` |
| `remark` | `VARCHAR(500)` | 是 | — | 检查项说明 |

`(inspection_id, item_code)` 唯一，其中 `item_code` 精确区分大小写；`ITEM` 与 `item` 是两个不同编码。检查项不单独作废或更新，随主记录整体解释。

## 3. 对外规则

- B 使用业务编码调用，不直接依赖内部 ID 或外键；
- 主记录与全部检查项在一个事务中创建；
- 记录创建后不可任意修改或物理删除；
- 纠错使用受控作废后新建；
- V7 不保存文件、动态 JSON、审批状态或梁状态副本。
