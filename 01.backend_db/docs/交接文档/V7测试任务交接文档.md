# V7 质量检查记录测试任务交接文档

## 1. 测试目标

独立验证 V7 是否符合 `docs/V7质量检查记录设计草案.md` 和数据字典。测试任务只修改测试与测试报告，不修改业务实现、迁移或正式契约。

## 2. 基线

- 依赖标签：`backend-db-v6.0.0`
- 包版本：`7.0.0`，尚未冻结
- 目标迁移：`e7b9c1d3f605`
- 测试数据库名称必须以 `_test` 结尾

## 3. 必测范围

1. 有检查项及无检查项的 `PASS`、`FAIL`；
2. 失败检查项与整体结果一致性；
3. 项目梁、全局梁和工序作用域；
4. V6 执行记录的项目、梁、工序和作废状态校验；
5. 同梁复检、多分支复检和跨梁拒绝；
6. 编码及外部来源幂等，检查项顺序无关比较，包括 `Z`、`a` 混合大小写顺序；
7. 首次并发创建、不同内容冲突及失败回滚；
8. 受控作废、重复作废和并发作废；
9. 筛选、页码分页、无总数分页和稳定排序；
10. 主从表字段、外键、唯一约束、检查约束和索引；
11. 迁移升级、降级、重新升级和模型一致性；
12. DTO、Protocol、组合工厂和 Wheel 隔离导入；
13. 不修改梁状态、V5 事件、V6 执行记录或 V3 审计；
14. V1 至 V6 完整回归。
15. `item_code` 的 `utf8mb4_bin` 数据库约束，并验证 `ITEM` 与 `item` 可同时存在且可重复幂等读取。
16. 列表查询不访问 `beam_quality_inspection_item`，单条 `get` 仍完整加载检查项。

## 4. 非目标

- 不测试或开发审批、签章、附件、放行和质量任务编排；
- 不增加 HTTP、鉴权、页面、消息或设备功能；
- 不测试运输、告警、二维码、RFID 或设备时序测点。

## 5. 通过标准

- 定向和完整测试无失败、错误、跳过或预期失败；
- 并发用例重复运行无死锁、超时或偶发失败；
- 测试库最终为 `e7b9c1d3f605 (head)` 且无模型差异；
- 不残留测试业务数据；
- 形成独立测试报告并给出是否建议进入审计的结论。
